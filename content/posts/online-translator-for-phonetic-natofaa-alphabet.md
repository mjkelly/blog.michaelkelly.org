I couldn't find any simple, quick translators for the [NATO Phonetic Alphabet](http://en.wikipedia.org/wiki/NATO_phonetic_alphabet) (you know, "Alpha! Bravo! Charlie!"), so I wrote [nato-alpha.appspot.com](http://nato-alpha.appspot.com) last night. (Yes, I tried alphabravocharlie.appspot.com, but it was taken.)

You can use the form, or you can use nice short URLs like [nato-alpha.appspot.com/test](http://nato-alpha.appspot.com/test).

It's not fancy, but it appears to mostly work. It's as much an excuse to learn Go on AppEngine and use a little Bootstrap 3 as it is an actual webapp. Code is [on GitHub](https://github.com/mjkelly/nato-alpha).
