I've been spending some weekends working on a little web game with my apartment-mate, [Hunter Freyer](http://www.hjfreyer.com/). The game is entitled _Marry Fuck Kill_. It's an online version of the parlor game where you must choose to marry, fuck, and kill each of three objects. The objects can be people, or other more abstract things.  
  
The web game lets you vote on items others have made, and make your own. It even has rounded corners!  
  
It's at the point where we're comfortable showing it off, and we think it's pretty fun, so check it out: [http://www.marryfuckkill.com](http://www.marryfuckkill.com/)
