Just switched the main page of michaelkelly.org to a static HTML file served by Amazon S3, from Google Sites. Did it out of curiosity, but size difference in between the HTML that Google Sites generates vs. my caveman HTML+CSS is interesting. 10x difference:  
  
Old Google Sites page: [https://sites.google.com/a/michaelkelly.org/main/](https://sites.google.com/a/michaelkelly.org/main/) =  17,360 bytes  
HTML page: [https://s3.amazonaws.com/www.michaelkelly.org/index.html](https://s3.amazonaws.com/www.michaelkelly.org/index.html) = 1,232 bytes
